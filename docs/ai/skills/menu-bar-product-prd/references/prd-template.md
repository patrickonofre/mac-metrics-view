# PRD Template

Use this shape for Mac Metrics View product docs.

## Sections

- Summary
- Problem
- Goals
- Non-goals
- Target users
- Core user stories
- Functional requirements
- UX requirements
- Technical requirements
- Privacy and security
- Performance requirements
- Acceptance criteria
- Open questions
- Future roadmap

## Acceptance Criteria Style

Write criteria as observable outcomes:

- The app appears in the menu bar after launch.
- The menu bar item shows a CPU percentage that updates periodically.
- The popover opens on click and shows more CPU/RAM detail.
- Quitting the app removes the menu bar item.
